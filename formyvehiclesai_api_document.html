ForMyVehiclesAI Api Document

Api Base Url:- https://api.formyvehicles.ai/api/v1

Header parameters:

  • X-Authorization:- JWT token
  • X-Device-Type:- 1 - Android , 2 - IOS
  • X-Device-Token:- device push token
  • X-Language:- 1 - en, 2 - ar
  • X-Timestamp :- 12355665767 (in millis)
  • X-Signature :- (HmacSHA1 Signature)
  • User-Agent :- {"buildNumber":1,"buildName":"1.0","deviceModel":"Mi A1"}
NOTE: Refer this link for errorCode handling: https://feedonomics.com/amazon-feed-error-codes/

JSON Object and Array Handling Instructions

With value:- user:{id,name} , without value:- user: null
With value:- vehicles:[{registrationNumber,brand}] , without value:- vehicles: null

Failure Response:-

{
  "hasError": true,
  "errorCode": 2020,
  "message": "Unauthorized access",
  "debugMessage": "Invalid Token",
  "response": null
}
{
  "hasError": true,
  "errorCode": 1001,
  "message": "Something wrong with data",
  "debugMessage": "Parameter missing (mobileNumber)",
  "response": null
}

1. User Registration Api:-

Api NameRegistration
MethodPOST
URLuser/registration
Params
{
  "name": "Krish Maitreyi",
  "state": "Kerala",
  "countryCode": "+91",
  "mobileNumber": "8921731641",
  "agreedTerms": true
}
Result
{
  "hasError": false,
  "errorCode": -1,
  "message": "Success",
  "response": {
    "tempUserId": 12,
    "mobileNumber": "8921731641",
    "countryCode": "+91"
  }
}
StatusDone
CommentstempUserId is the primary key of the temporary user table.
Sends 4-digit OTP to user's mobile number.
